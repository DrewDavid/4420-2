This was programmed on PyCharm, requiring gymnasium, numpy, and matplotlib, and can be loaded onto one's machine by simply cloning the repository. Hyperparameters can be modified in the agent class definition, and episode count can be modified within the main block. From there, run cliff_walking_agent.py. After training is complete, a graph showing episode score v. episode will appear. Closing the graph window will bring up a prompt to run a 30-episode, no-exploration evaluation. Confirming will display a new graph showing the score for those 30 episodes. After closing out of this window (or after denying the extra evaluation), a video of the final (best) policy will be saved to the trained_video folder in the same directory as the program.
